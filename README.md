# Grader

Веб-приложение для автоматической проверки рукописных ответов с помощью нейросети. Учитель вводит задание, критерии оценивания и загружает фото работы - система отправляет все в GPT-4o Vision и возвращает оценку по 10-балльной шкале, список ошибок и развернутый комментарий. Есть режим групповой проверки, когда работы нескольких учеников проверяются за один раз параллельными запросами.

---

## Что умеет

- Регистрация и вход (хешированные пароли, Flask-сессии)
- Режим «Один ученик» - проверяет работу одного ученика, результат сохраняется в базу
- Режим «Весь класс» - проверка нескольких учеников разом, запросы к AI идут параллельно
- Группы (сессии проверки) - учитель создает группу («Контрольная №3, 9А»), все результаты привязываются к ней
- Загрузка JPG/PNG или ZIP-архива до 5 МБ (в архиве до 10 фото - они считаются одной работой)
- Предпросмотр фото перед отправкой
- Результат: оценка, список ошибок, комментарий нейросети
- Журнал результатов с фильтром по группе и удалением отдельных записей
- Экспорт журнала в CSV (с колонкой «Группа»)

## Как запустить

### Вариант 1 - через Docker (проще всего)

Нужен Docker и docker-compose.

```bash
git clone <репозиторий>
cd <папка>
cp .env.example .env
# заполнить OPENAI_API_KEY и SECRET_KEY
docker-compose up --build
```

Открыть [http://localhost:5000](http://localhost:5000). База создается автоматически при первом запуске.

### Вариант 2 - без Docker

Нужен Python 3.11+ и PostgreSQL.

```bash
cp .env.example .env
# заполнить DATABASE_URL, OPENAI_API_KEY, SECRET_KEY
pip install -r backend/requirements.txt
python backend/app.py
```

Открыть [http://localhost:5000](http://localhost:5000).

## API

| Метод | URL | Описание |
|---|---|---|
| `POST` | `/api/register` | Регистрация, поля `email` и `password` |
| `POST` | `/api/login` | Вход, поля `email` и `password` |
| `POST` | `/api/logout` | Выход, нужна активная сессия |
| `GET` | `/api/me` | Текущий пользователь, нужна сессия |
| `GET` | `/groups` | Список групп текущего пользователя, нужна сессия |
| `POST` | `/groups` | Создать группу; JSON: `name`, `description` (необязательно) |
| `DELETE` | `/groups/<id>` | Удалить группу (только свою), нужна сессия |
| `POST` | `/check` | Проверить работу; multipart: `task`, `criteria`, `image`, `student_name`, `save`, `group_id` (необязательно) |
| `GET` | `/results` | Журнал результатов; query param `group_id` - фильтр по группе |
| `DELETE` | `/results/<id>` | Удалить запись (только свою), нужна сессия |
| `GET` | `/export/csv` | Скачать журнал в CSV, нужна сессия |

Все защищенные маршруты возвращают `401`, если сессии нет.

## База данных

### Таблица `users`

| Поле | Описание |
|---|---|
| `id` | Первичный ключ |
| `email` | Уникальный |
| `password_hash` | PBKDF2-SHA256 через werkzeug |
| `created_at` | Дата регистрации |

### Таблица `groups`

| Поле | Описание |
|---|---|
| `id` | Первичный ключ |
| `user_id` | Внешний ключ -> `users` |
| `name` | Название группы |
| `description` | Описание (необязательно) |
| `created_at` | Дата создания |

### Таблица `results`

| Поле | Описание |
|---|---|
| `id` | Первичный ключ |
| `user_id` | Внешний ключ -> `users` |
| `group_id` | Внешний ключ -> `groups` (необязательный) |
| `student_name` | Имя ученика |
| `task` | Текст задания |
| `criteria` | Критерии оценивания |
| `score` | Оценка 0-10 |
| `comment` | Комментарий нейросети |
| `errors` | Список ошибок (JSON) |
| `created_at` | Дата проверки |

Индексы на `results(user_id)`, `results(created_at DESC)` и `results(group_id)` ускоряют выборку журнала.

## Безопасность

- **Пароли** - хранятся как PBKDF2-SHA256-хеш через werkzeug
- **SQL-инъекции** - исключены: SQLAlchemy ORM не подставляет значения напрямую в строку запроса
- **XSS** - Jinja2 экранирует вывод, пользовательский ввод не вставляется через innerHTML
- **CSRF** - для всех POST/PUT/PATCH/DELETE-запросов сервер проверяет токен из заголовка `X-CSRF-Token` против значения в сессии через `hmac.compare_digest`. Токен генерируется через `secrets.token_urlsafe(32)`, рендерится в `<meta name="csrf-token">` основной страницы и недоступен сторонним сайтам благодаря same-origin policy. Сессионная cookie дополнительно помечена `HttpOnly` и `SameSite=Lax` как defense-in-depth
- **Авторизация** - `/check`, `/results`, `/groups`, `/export/csv` проверяют `session["user_id"]`
- **Контроль доступа** - удаление результатов и групп работает только если `user_id` совпадает с сессией. При сохранении результата с привязкой к группе сервер дополнительно проверяет, что переданный `group_id` принадлежит текущему пользователю — иначе запрос отклоняется с кодом 400 (защита от IDOR)
- **Секреты** - в `.env`, который исключен из git через `.gitignore`

## Пользовательские сценарии

### Учитель проверяет одного ученика

1. Зарегистрироваться / войти
2. Открыть вкладку «Один ученик»
3. Ввести задание, критерии, ФИО ученика
4. Загрузить фото (JPG/PNG) или ZIP с несколькими страницами работы
5. Нажать «Проверить и сохранить» - получить оценку, ошибки и комментарий

### Учитель проверяет всю группу

1. Открыть вкладку «Весь класс»
2. Выбрать группу из списка или создать новую кнопкой «+ Новая»
3. Ввести общее задание и критерии
4. Добавить учеников кнопкой «+», указать ФИО и загрузить фото каждому
5. Нажать «Проверить всех» - запросы к AI уходят параллельно
6. Все результаты сохраняются в журнале и привязываются к группе

### Просмотр и экспорт

1. Открыть вкладку «Результаты»
2. Выбрать группу в фильтре - журнал обновится автоматически
3. Удалить ненужные записи
4. Скачать CSV для анализа в Excel или Google Sheets
